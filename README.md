# thetalkofthomas — Fullstack Next.js 15 & Supabase Blog

Hệ thống blog cá nhân hoàn chỉnh theo phong cách **Editorial Minimalist & Peaky Blinders Stoicism** (Không AI Slop, đúng 2 font chữ, giao diện sạch tuyệt đối), có sẵn trang quản trị để đăng nhập và đăng bài.

---

## 1. Khởi chạy thử nghiệm trên máy (Local Development)

Mở terminal trong thư mục này và chạy lệnh:

```bash
npm run dev
```

Sau đó mở trình duyệt tại cổng riêng biệt **3333**:
* **Trang chủ công khai:** `http://localhost:3333`
* **Trang đăng nhập quản trị:** `http://localhost:3333/login`
* **Bảng điều khiển Admin:** `http://localhost:3333/admin`
